# Prompt de retomada

Continue a implementação da Distribuidora de Cana Engenheiro Ltda sem reiniciar o projeto. Leia `COMECE_AQUI.md`, `cerebro/01_VISAO_CANONICA.md`, `plano/FASES.md`, o checkpoint mais recente e as evidências citadas. Inspecione o código e o git antes de escrever.

Responda primeiro, de forma curta: fase atual, último gate comprovado, alterações locais existentes, bloqueios e próxima fatia verificável. Em seguida, execute a fatia. Um relatório antigo não substitui os testes de regressão necessários ao código atual.

Preserve os quatro aplicativos independentes e a paridade do App Patrão com a web. Não remova recursos, gráficos 3D, permissões ou trilha para simplificar. Não promova simulação a integração real. Bloqueios externos devem ser descritos com insumo preciso e trabalho independente concluído.

Se checkpoint e implementação divergirem, registre a divergência e atualize o estado com evidências. Não invente PASS para manter a ordem do plano. Use a fase correspondente à lacuna real e continue pelo roteiro.
