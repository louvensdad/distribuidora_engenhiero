# Uso dos assets

SVGs de interface em viewBox24, traço1.7 e `currentColor`. Importar como componente Angular ou converter de forma controlada para o pacote vetorial Flutter. Usar o mesmo nome do mapa; não misturar famílias de ícones em uma mesma barra.

Ícones de aplicativo em `apps`, SVG e PNG1024, cada um com identidade própria e a marca comum. São artes-base: a fase de build deve gerar densidades Android, adaptive icon com área segura e AppIcon iOS conforme ferramentas oficiais. PNG1024 não é um conjunto completo de assets de loja.

Logos em `marca` são propostas. Aprovar com o dono antes de publicação. Não trocar o nome da empresa por nomes genéricos da demonstração antiga.
