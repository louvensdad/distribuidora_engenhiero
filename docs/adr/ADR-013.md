# ADR-013: Nome da capacidade de gestão de permissões

Data: 14/11/2026. Estado: ADOTADA.

## Contexto
`cerebro/04_ACESSOS_E_APLICATIVOS.md` diz que a API de permissões exige `permissions.manage`.
`contratos/permissoes.json` define para `permissions` apenas as ações `view` e `edit_draft`.

## Decisão
Usar o contrato (`permissions.edit_draft`) como a capacidade que autoriza alterar acessos de outra pessoa, mantendo
a regra mais restritiva do cérebro: além da capacidade, o servidor proíbe alterar o próprio acesso, conceder
capacidade que o próprio concedente não possui e remover o último administrador ativo.

## Consequência
Contrato e código usam `permissions.edit_draft`. Se o dono preferir um nome distinto (`manage`), atualizar
`permissoes.json` e o catálogo de capacidades juntos.
