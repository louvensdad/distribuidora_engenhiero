# ADR-015: Site do patrão em React + Vite (Node) em vez de Angular

Data: 14/11/2026. Estado: ADOTADA. Substitui a parte web da ADR-002.

## Contexto
A ADR-002 (proposta do pacote) indicava Angular para a web. O responsável pediu explicitamente que o site
seja escrito com Node e React.

## Decisão
`apps/web-admin`: React 19 + TypeScript + Vite, react-router, testes com Vitest/Testing Library e Playwright.
Versões exatas no `package.json` e `package-lock.json` (apenas versões publicadas há pelo menos duas semanas).
Fontes Manrope/DM Sans distribuídas localmente (pacotes @fontsource, licença OFL), sem fonte remota.

## O que não muda
- O site continua sendo um cliente do BFF: login no servidor, cookie de sessão HttpOnly, CSRF por cabeçalho,
  nenhum token no navegador (SEC-06).
- Servido na mesma origem da API (proxy do Vite em desenvolvimento; proxy reverso em produção), sem CORS.
- A autorização continua no servidor; o React só usa `/api/v1/me/capabilities` para montar menus.
- Mobile continua Flutter (ADR-002, parte móvel).

## Consequências
`toolchain.lock.json` passa a registrar React/Vite em vez de Angular. Requisitos UX-01..05 e WEB-01..03 se aplicam
igualmente. Nenhuma lógica de dinheiro ou permissão é replicada no frontend.
